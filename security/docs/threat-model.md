# Mini threat model — index9

## Scope

Публичный учебный кейс `Система обучения — Мосэнерго`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Безопасные логи и жизненный цикл инцидента

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Чувствительные логи | В журнал попадают имя, email, телефон, токен или полный свободный ввод | Событийные логи + редактирование чувствительных ключей |
| T2 | Нет корреляции | События нельзя связать в одну попытку/инцидент | correlation_id/request_id без ПДн |
| T3 | Нет triage | Ошибка фиксируется, но не классифицируется | severity + runbook triage/contain/recover |
| T4 | Избыточный stack trace | Внешний интерфейс показывает внутренности | Минимальная ошибка пользователю, детали только локально |
| T5 | Потеря доказательств | Логи изменяются без контроля | append-only подход для учебного журнала + временные метки |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
