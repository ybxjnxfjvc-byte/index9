# Incident runbook — локальная учебная среда

1. **Detect:** зафиксировать тип события, время, correlation_id и симптом без ПДн/секретов.
2. **Triage:** определить severity, затронутый компонент и воспроизводимость.
3. **Contain:** остановить локальный сервис/отключить проблемный endpoint, не удаляя доказательства.
4. **Eradicate:** устранить первопричину, добавить тест на регрессию.
5. **Recover:** перезапустить локально, проверить health и основной пользовательский сценарий.
6. **Retrospective:** записать причину, контроль и то, что изменено в тестах/документации.
