# Evidence map — index9

| Параметр | Значение |
|---|---|
| Кейс | Система обучения — Мосэнерго |
| Security-направление | Безопасные логи и жизненный цикл инцидента |
| Тип | опорный практический |
| Опорный кейс направления | index9 |
| Проверяемая поверхность | публичный репозиторий / браузер / локальная учебная среда |

## Какие навыки подтверждаются

| № | Риск / навык | Проверяемый контроль |
|---:|---|---|
| 1 | Чувствительные логи | Событийные логи + редактирование чувствительных ключей |
| 2 | Нет корреляции | correlation_id/request_id без ПДн |
| 3 | Нет triage | severity + runbook triage/contain/recover |
| 4 | Избыточный stack trace | Минимальная ошибка пользователю, детали только локально |
| 5 | Потеря доказательств | append-only подход для учебного журнала + временные метки |

## Артефакты этого кейса

- `SECURITY.md` — scope и ограничения;
- `EVIDENCE.md` — карта доказательств;
- `security/docs/threat-model.md` — модель угроз;
- `security/tests/manual-security-checklist.md` — ручной сценарий проверки;
- `security/lab/`, `security/scripts/`, `security/tests/python/` и/или CI — исполняемая практика этого направления.

## Не доказывается

- доступ к системам реальной организации;
- эксплуатация уязвимостей внешних сервисов;
- промышленная безопасность инфраструктуры;
- соответствие конкретному отраслевому стандарту без отдельного аудита.
